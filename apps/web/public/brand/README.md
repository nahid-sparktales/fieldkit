# Navigated Support artwork

Original, unmodified SVG artwork and the 180-pixel Apple touch icon from the
owner-supplied Navigated-Support-Logo-Kit.zip. See docs/branding.md and the
included brand guide for palette, clear space and minimum sizes.

Use horizontal-light.svg on light backgrounds and horizontal-dark.svg on dark
backgrounds. icon-charcoal.svg is the staff app mark and SVG favicon.
